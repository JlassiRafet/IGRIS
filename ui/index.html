Agent Orchestration

You send a request from any chat app. Hermes, your assistant, asks the decision layer (Laya or Jev) to pick the right agent, model and risk level. A builder agent writes the code and a reviewer agent checks it, each in its own Herdr pane, and either one can ask the decision layer mid-task. The shell runs the tests, and Hermes reports back to you. Pick your own tools in Your setup, and hover or tap any part to see what it does.
